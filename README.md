# 弹窗沿爱心线依次弹出 ♥

小弹窗按心形参数方程沿线取点，逐个弹出，弹完正好描出一个爱心轮廓。

对比网上常见的「随机位置弹窗」，这里的每个弹窗位置都由心形曲线决定
（MathWorld Heart Curve：`x=16sin³t, y=13cost−5cos2t−2cos3t−cos4t`），
所以弹窗落点是沿着爱心线稿排列的，不是随机乱撒。

## 在线演示

<https://www7398.github.io/heart-popups/>

手机打开会自动切换成 40 个小弹窗的紧凑版，电脑是 72 个。

## 自定义

全部在 `index.html` 顶部的脚本里改：

- `PHRASES` —— 弹窗文字，按顺序循环使用
- `N` —— 沿爱心线取多少个点（弹窗数量，手机端自动用 40）
- `STEP_MS` —— 每个弹窗的间隔毫秒数
